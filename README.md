## 🚀 Featured Projects

### [SynapNCore](https://github.com/Freddy78974/SynapNCore) — *privé*
Projet personnel d'architecture logicielle : une plateforme modulaire orientée IA et automatisation, structurée autour d'un Kernel pensé pour découvrir, valider, charger, activer et gérer des modules indépendants.

**Le projet est actuellement en phase de conception et de spécification** : le dépôt suit un processus de gouvernance documentaire strict (RFC → ADR → SPEC, avec statuts *Proposé/Accepté* et registre d'approbation) et ne contient pour l'instant aucune implémentation. TypeScript/Node.js, PostgreSQL et Redis sont envisagés pour le Core lors du passage à l'implémentation.

*Démontre : System Design · Modular Architecture · Technical Documentation · Architecture Decision Records*

### [GestFinFam](https://github.com/Freddy78974/GestFinFam) — *privé*

A notamment nécessité l'analyse d'un bug spécifique au comportement d'une PWA Flutter sur iOS après fermeture puis réouverture de l'application : reproduction, instrumentation, correction, validation sur appareil réel.

*Stack : Flutter · Firebase · Firestore · PWA*
*Démontre : Cross-Platform Development · Debugging · Real-Device Testing*

### [EditLetter](https://github.com/Freddy78974/EditLetter) — *privé*
